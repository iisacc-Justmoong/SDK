# 동적 라이브러리 빌드

iiVolumetricSolidMesh 라이브러리는 기본적으로 공유 라이브러리로 빌드한다.
`BUILD_SHARED_LIBS=OFF`는 동적 로더를 사용할 수 없는 환경 등을 위한 명시적
정적 빌드 선택이다. Windows에서는 DLL과 가져오기 라이브러리, iOS에서는
프레임워크, WebAssembly에서는 사이드 모듈로 구성한다. 앱에는 사용한 모듈과
그 런타임 종속성만 패키징한다.

기본 공유 빌드 검사는 대상 유형과 테스트 실행 파일의 직접 동적 연결을 확인한다.
플랫폼별 구성은 해당 도구 체인으로 빌드해야 하며 이 검사가 다른 운영체제나
실기기에서의 실행을 보장하지는 않는다.
