# 검증 상태

## iiGPU 통합 후 검증

2026-10-27 macOS arm64에서 iiGPU와 WebGPU 구성요소를 함께 빌드하고 CTest
27/27을 통과했다. Metal·Vulkan 및 Dawn/Metal 연산, 브라우저 없는 텍스처
렌더링, 기존 이름과 새 이름을 함께 사용하는 이동 설치 소비자, 대상별 Dawn
경로 선택을 포함한다. 구성요소를 끈 기본 GPU 빌드는 별도로 4/4를 통과했다.
Windows·Linux에 대한 실제 빌드나 실행은 수행하지 않았다. Vulkan의 비표준 SDK
경로는 설치 소비자 구성에 전달했다. 이후 소스 변경의 검증은 해당 실행 기록을
확인해야 한다.

## iiWebGPU 병합 전 기록

아래 기록은 병합 전 iiWebGPU의 검증 증거이다.

검증일은 2026-10-27이다. macOS arm64 호스트의 Apple M1 Max 통합 GPU에서 Dawn의 Metal 백엔드를 사용하였다. AppleClang 21과 CMake 4.4.4로 빌드하였다. 고정 공급자는 Dawn v20261023.194543, 리비전 1716e88cc9e58398fab5d4473f7f2e858667b677이다.

## 빌드와 검사

| 구성 | 결과 | 범위 |
| --- | --- | --- |
| Release | CTest 10/10 통과 | 의존성 도구, 설치 이동 소비자, 할당, 텍스처 크기, 기능 협상, 컴퓨트, 렌더링, 검증 오류, 수명, 사용 예제 |
| Debug + ASan + UBSan | CTest 9/9 통과 | 같은 계약과 설치 이동 소비자; 별도 예제 실행 타깃은 비활성 |
| 공개 헤더 | 6개 독립 컴파일 통과 | Result, Memory, Native, Texture, WebGPU, Arena |
| 의존성 도구 | Python 검사 5/5 통과 | 정확한 대상 선택, 기존 파일 보존, 해시 오류, 경로 이동·링크 거부, 잠금 데이터 |

ASan·UBSan은 iiWebGPU와 이를 링크하는 설치 소비자를 계측하였다. 사전 빌드된 Dawn 아카이브 내부에 계측을 추가한 것은 아니다.

## 실제 GPU 실행

- 컴퓨트: 256바이트 뒤에서 시작하는 부분 할당 버퍼에 1,024개 uint32 값을 전송하고 WGSL 커널로 values × 3 + 7을 계산하였다. 16777217과 UINT32_MAX를 포함한 모든 회수 결과가 C++의 정확한 uint32 기준과 일치하였다. CPU 대체 실행은 없다.
- 렌더링: WGSL 정점·프래그먼트 셰이더로 16×16 RGBA8 텍스처에 삼각형을 그렸다. 텍스처를 행당 256바이트 정렬의 회수 버퍼로 복사하고 256개 픽셀의 RGBA를 모두 확인하였다.
- 기능: timestamp-query를 어댑터에서 확인하고 필요한 기능으로 요청한 뒤 장치의 활성 기능과 2개 항목의 쿼리 집합 생성을 확인하였다. 지원 범위를 초과한 필수 한도 요청은 실패하였다.
- 전송·매핑: 큐 쓰기, 버퍼 복사, 쓰기 가능한 staging 매핑, GPU 전송 뒤 읽기 매핑을 확인하였다. 읽기 전용 권한, 이중 매핑, 정렬·범위 오류, 매핑 중 GPU 사용을 검사하였다.

## 수명과 실패

버퍼 예산 초과·축소 실패, 산술 오버플로, 자유 영역 병합, 공유 임대의 최종 반환과 8개 스레드의 동시 할당을 검사하였다. 잘못된 WGSL·버퍼 사용 조합·텍스처 뷰를 백엔드 오류로 반환하고 실패한 예약을 회수하였다.

인코딩 중인 영역과 제출 후 미완료 영역은 재할당되지 않았다. 완료 콜백 뒤에는 같은 전체 영역을 다시 할당할 수 있었다. 텍스처 뷰는 원본 텍스처 변수를 제거해도 논리 예약을 유지하였으며 마지막 뷰 제거 때 이를 반환하였다.

원래 Device 변수를 제거한 뒤에도 보유 중인 Future의 할당과 매핑이 완료되는 것을 검사하였다. 반대로 관찰하지 않은 비동기 작업과 대기 중인 콜백을 남겨 둔 8회의 인스턴스 정리를 ASan·UBSan 구성에서도 수행하였다. 명시적인 장치 파괴, 재제출 거부, 시간 초과가 매핑을 취소하지 않는 계약도 확인하였다.

## 패키지와 재현 증거

RelocatedConsumer 검사는 패키지를 임시 위치에 설치하고 다른 경로로 이동한 뒤, 원래 설치 디렉터리가 없는 상태에서 find_package(iiWebGPU)를 수행하였다. 별도 소비자의 빌드와 1,024개 값의 GPU 실행이 통과하였다. DYLD_*와 LD_LIBRARY_PATH 환경 변수 없이 실행하였고 Qt·Core 런타임이 타깃으로 들어오지 않도록 확인하였다.

최종 사용 패키지는 build/package에 설치한다. build/verification.json에는 소스·아카이브 해시와 실행 결과를 기록한다. 원본 기록은 다음 경로에 있다.

- build/Testing/Temporary/LastTest.log
- build/sanitize/Testing/Temporary/LastTest.log
- build/relocation-report.json
- build/sanitize/relocation-report.json
- build/documentation/verify-report.json

## 검증 경계

Windows·Linux에는 대상별 공급자 자산과 공통 네이티브 API 경로를 제공하지만 이번 작업에서 해당 플랫폼을 빌드·실행하지 않았다. iOS·Android의 대상용 공급자·툴체인 빌드와 실기기 실행도 수행하지 않았다. Web/WASM 패키지와 브라우저 실행은 제공·검증하지 않았다.

표준 C API를 통한 표면 구성·획득·표시 경로는 노출하였지만 실제 창에 표시하는 검사는 수행하지 않았다. 컴퓨트와 렌더링의 완료·결과 일치는 검증하였으며 GPU와 CPU의 처리 시간 비교나 속도 향상률을 측정한 것은 아니다.
