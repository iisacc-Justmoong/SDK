# 동적 라이브러리 빌드

GPU, 선택적 런타임과 WebGPU 구성 요소는 기본적으로 각각 공유 라이브러리로
빌드한다. 기존 정적 연결은 `BUILD_SHARED_LIBS=OFF`로 선택한다. Windows DLL,
iOS 프레임워크, WebAssembly 사이드 모듈에 맞춰 설치하며 대상별 Dawn 배포본과
플랫폼 GPU 런타임이 필요하다. 선택한 SDK 기능과 필요한 런타임만 앱에 포함한다.

공유 연결 테스트는 대상 유형과 소비 실행 파일의 종속성을 확인하며 앱을 띄우거나
GPU 실행을 보장하지 않는다. 장치 가속은 별도 환경에서 검증해야 한다.

Emscripten 소비자 설정은 공유 사이드 모듈을 가져오기 전에 CMake의 공유 라이브러리 지원을 활성화한다. 앱의 메인 모듈 컴파일·링크 옵션은 빌더 또는 앱이 지정해야 한다.
오래된 Emscripten C++ 라이브러리에서는 취소 토큰 지원을 검사하고 필요한 실험적
라이브러리 옵션을 소비자에게 전달한다. 완료 관찰 런타임은 pthread가 필요하다.
설치된 런타임은 연쇄 iiGPU 사이드 모듈을 찾도록 링크 검색 경로도 제공한다.
